# Ecosistema EduWit para Arduino

Libreria unificada para la ensenanza de robotica y sistemas embebidos de **EduWit**.

## Shields compatibles:
- **EduBoard UNO:** Shield de inicio sobre Arduino UNO.
- **EduBoard Profesional:** Shield modular sobre Arduino Nano (Proximamente).

Disenada para operar de manera transparente con `#include <EduWit.h>`.
